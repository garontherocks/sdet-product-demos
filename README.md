# SDET Product Demos

Sanitized, reproducible evidence for productized Senior SDET services by Víctor Aller.

## Playwright Automation Bootstrap

The first demo contains a deterministic storefront, a Playwright TypeScript UI/API suite, CI, HTML/JSON reporting, screenshots, videos and generated metrics.

```bash
npm ci
npx playwright install chromium
npm run test:bootstrap
npm run metrics
```

Public contents demonstrate outcomes only. The reusable commercial frameworks, generators and delivery methodology remain in private repositories.

## Evidence policy

- no customer code, credentials, domains or data
- metrics are scoped to deterministic demo runs
- CI artifacts provide reports, traces and videos
- screenshots and videos are regenerated by the public test suite
